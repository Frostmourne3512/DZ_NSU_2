# DZ_NSU_2

Домашние задания по Python (НГУ).

## Содержимое

В репозитории собраны решения задач в виде отдельных скриптов `task1.py` … `task23.py`.
Каждый скрипт запускается независимо и, как правило, читает данные через `input()`.

## Запуск

```bash
python task1.py
```

Требуется Python 3.10+ (внешние зависимости не используются).
